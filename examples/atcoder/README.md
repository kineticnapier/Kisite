# AtCoder examples

Small AtCoder solutions written in Kisite.

| Problem | File | Main features used |
|---|---|---|
| [ABC081 A - Placing Marbles](https://atcoder.jp/contests/abc081/tasks/abc081_a) | [`abc081_a.kis`](abc081_a.kis) | string input, foreach, condition |
| [ABC047 C - 1D Reversi](https://atcoder.jp/contests/abc047/tasks/arc063_a) | [`abc047_c.kis`](abc047_c.kis) | string iteration, state update |
| [ABC170 A - Five Variables](https://atcoder.jp/contests/abc170/tasks/abc170_a) | [`abc170_a.kis`](abc170_a.kis) | multiple input, arrays, foreach, break |

Run one with standard input, for example:

```bash
python kisite.py examples/atcoder/abc081_a.kis
```

These examples are kept small so they also work as practical syntax samples.
